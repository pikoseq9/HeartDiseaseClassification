# Heart Disease Classification

This repository contains code and resources for building, training, and evaluating models to classify heart disease from clinical data. The primary goal is to leverage machine learning techniques to help predict the presence of heart disease based on patient information.

## Features

- Data preprocessing and feature engineering
- Support for multiple classification algorithms (e.g., Logistic Regression, Random Forest, SVM)
- Model evaluation metrics (accuracy, precision, recall, F1-score, ROC-AUC)
- Visualization of results and model performance
- Jupyter notebooks and Python scripts for reproducibility

## Dataset

The project uses publicly available heart disease datasets available on the Kaggle platform, originally sourced from the Cleveland Clinic Foundation. The dataset includes features like age, gender, chest pain type, resting blood pressure, cholesterol levels, fasting blood sugar, and more.

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/pikoseq9/HeartDisaeseClassification.git
    cd HeartDisaeseClassification
    ```

### Usage

- Run the main notebook or script to start training and evaluating models:
    ```bash
    python main.py
    ```
